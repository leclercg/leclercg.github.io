Financial Restructuring Application

Single-page application + REST API for a company proposing financial restructuring.

Overview

Modern web application replacing a legacy process: a responsive SPA (Javascript MVC) backed by a Java REST API. Delivered a maintainable, test-driven solution focused on reliability, performance and long-term evolvability.

Role & Responsibilities

  • Built the front-end SPA using a Javascript MVC framework (React/Angular-style patterns).
  • Designed and implemented REST endpoints in Java (Spring / J2EE patterns).
  • Applied TDD and automated unit/integration tests (JUnit/TestNG, JS test tools).
  • Led code-quality and performance work (CI with Jenkins, static analysis, profiling).
  • Participated in Scrum ceremonies and cross-discipline design decisions; contributed to R&D efforts.

Key Technologies

Java, Spring / Play patterns, REST, JSON, Javascript (React/Angular/Backbone patterns), SQL Server, Git, Jenkins, JUnit/TestNG, Bash.

Outcomes

  • Replaced fragile legacy tooling with a maintainable web platform.
  • Improved reliability and test coverage through TDD and CI pipelines.
  • Delivered faster feature cycles and clearer handover documentation for long-term maintenance.

Why this project mattered

The work reduced manual effort for restructuring proposals, increased throughput, and made the product approachable for future teams while keeping performance and reliability priorities.
